오늘의 모의 통장

다음 게임 후보

① 조건 하나 바꾸기

같은 속력으로 동쪽을 향하던 배가 서쪽으로 돈다. 아이는 ‘속력만 / 속도만 / 둘 다 / 둘 다 그대로’ 중 실제로 바뀐 것을 고른다. 다음에는 방향은 그대로, 속력만 바꿔 같은 개념을 다시 쓴다. 가장 먼저 시험해 볼 후보.

② 이야기 되감기

새 그림 세 장에서 마지막 장면이 먼저 보인다. ‘미나가 자기 짐작을 고쳤다’ 바로 전에 있었던 일을 세 장 중 고르고, 한 번 더 거슬러 올라간다. 오답 그림에는 같은 인물이 등장하되 사건의 원인이나 순서가 다르다. 두 연결을 다 고른 뒤 짧은 장면을 순서대로 본다.

③ 한 장씩 분류하기

두 동물 이름표를 읽고 ‘같은 종 / 같은 속·다른 종 / 다른 속’ 중 한 서랍에 넣는다. 철자가 비슷한 카드, 둘째 말만 같은 카드, 두 말 모두 같은 카드를 섞는다. 새 이름표 세 쌍을 모두 분류하면 무엇을 기준으로 나뉘었는지 보여 준다.

출제 기준

듣기 첫 출제는 열 문장의 앞·중간·끝에서 하나씩 고른다. 각 구간에서 핵심 개념, 인물 판단의 변화, 사건의 원인을 우선한다. 중요도가 같으면 섞는다. 재시험은 틀린 자리 하나와 다른 두 자리로 짠다. 여러 개 틀렸다면 틀린 자리가 차례로 돌아오고, 새 자리가 소진되면 가장 오래전에 풀었던 자리를 쓴다.

과학은 네 문장의 여덟 개 의미 단위를 끝까지 복원한다. 네 번째 오답이면 바로 네 문장을 다시 본다. 그림 문제는 같은 그림에서 초점을 바꿔 한 문장씩 묻고, 보기는 그 문장의 행동·성질·양 중 한 종류로 맞춘다.

판단의 근거

초등학생도 읽은 뒤 기억에서 꺼낸 단어를 다시 공부만 한 단어보다 오래 기억했다. 여기서는 답을 고를 때 공부 카드를 닫는다. Karpicke 등, 2016

그럴듯한 오답은 학생이 여러 후보의 뜻을 기억해 구분하게 할 수 있다. 보기마다 ‘왜 이 문장에는 안 맞는가’를 설명할 수 있어야 채택한다. Little·Bjork, 2015

읽은 글로 푼 선택형 시험에서는 피드백을 늦춰 준 조건이 즉시 준 조건보다 나중 회상에 유리했다. 세 번째 선택 뒤 공개하는 간격은 이번 목업에서 시험할 값이다. Butler 등, 2007

다른 예에 같은 개념을 적용해 본 학생들이 나중의 새로운 예에서도 더 잘 풀었다. 조건과 장면이 바뀌는 후보를 넣은 이유다. Butler 등, 2017 온라인판

강의를 중간 단위로 나눠 기억 문제를 낸 실험에서는 주의 이탈이 줄었다. 열 문장·세 빈칸·네 번 오답은 서아의 실제 사용에서 조절할 기준이다. Szpunar 등, 2013
